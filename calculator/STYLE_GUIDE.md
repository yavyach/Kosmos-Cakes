# Инструкция по правкам стиля

Все правки **визуала** делаются в одном файле:

```
calculator/style.css
```

После правки → `push.bat` двойным кликом → через минуту обновится сайт и все iframe-ы.

---

## 1. Цвета (палитра)

Файл `style.css`, строки **32–40** — блок `:root{ ... }`.

```css
:root{
  --bg:        #cfcfcf;   /* серый фон калькулятора */
  --red:       #D2363C;   /* большие красные цифры, описание-белый, ховер дропдаун-опций (текст) */
  --pink:      #F16471;   /* основной розовый: название торта, +/-, бордеры, кнопка «далее» */
  --rose:      #E55264;   /* розовый при наведении (hover) */
  --red-deep:  #B0202A;   /* зарезервировано (если понадобится) */
  ...
}
```

| Хочешь поменять | Какую переменную |
|---|---|
| Серый фон калькулятора | `--bg` |
| Большие красные цифры (вес, ярусы, итог) | `--red` |
| Название торта (крупное розовое) | `--pink` |
| Кнопки +/− | `--pink` (hover — `--rose`) |
| Бордеры дропдаунов и кружочки фикс-веса | `--pink` (hover — `--rose`, выбран — `--red`) |
| Кнопка «далее» (текст и искорка) | `--pink` (hover — `--rose`) |
| Текст опции при наведении в дропдауне | `--red` на фоне `--pink` |

## 2. Шрифты

Файл `style.css`, строки **7–24**.

- **ALS Beast Ultra** (`var(--display)`) — для крупных надписей: название торта, белое описание, цифры, лейблы «Сколько килограмм?» / «Начинка», итоговая стоимость, кнопка «далее».
- **Golos Text Regular** (`var(--text)`) — для мелкого: дропдауны, подсказки, «начинка N ярус».

Чтобы целиком подменить шрифт — поменяй имя в `:root` (строки 38–39).

## 5. Чего НЕ нужно править руками

- `core.js` — там логика (цены начинок, формулы расчёта). Если меняется цена начинки — это там, объект `FILLING_PRICES` (строки 5–12).
- `cakes/*/*.html` — 30 готовых файлов, генерируются из `build_cakes.py`. Не правь их по отдельности.
- `assets/` — шрифты.

---

## 6. Быстрый чек-лист «как поменять и увидеть результат»

1. Открыла `calculator/style.css` в любом редакторе.
2. Нашла нужную строку из таблицы, поменяла число/цвет.
3. Сохранила.
4. Двойной клик на `kosmos_calc/push.bat` → Enter → ждёшь «Готово!».
5. Через ~1 минуту обновляешь страницу с калькулятором (Ctrl+F5) — изменения применились.

То же касается `core.js`, если меняется цена начинки.

## 7. Если хочется поменять формулу или поведение

`core.js`:

| Что | Где |
|---|---|
| Цены начинок (рубли за кг) | `FILLING_PRICES` — строки 5–12 |
| Наборы начинок по типам тортов | `FILLING_SETS` — строки 16–23 |
| Логика типа 1 (ярусный) | `renderTieredCake` |
| Логика типа 2 (фикс. вес 2.5/3.5) | `renderFixedCake` |
| Логика типа 3 (плоский по весу) | `renderWeightCake` |
| Максимальный размер слова в заголовке | `fitTitle({max:96, min:26})` |

Параметры конкретного торта (мин. вес, мин. ярусы, стоимость декора, набор начинок) лежат в `build_cakes.py` в массиве `CAKES`. Если меняется параметр одного торта:
1. Открой `build_cakes.py`, найди нужный торт в `CAKES`, поправь.
2. В корне репозитория: `python build.py` — перегенерирует калькуляторы и страницы сайта.
3. `push.bat` — залить на сайт.

## 8. Структура папок

```
calculator/
  index.html             ← лендинг
  style.css              ← стили калькулятора
  core.js                ← логика
  build_cakes.py         ← генератор calculator/cakes/
  cakes/                 ← 30 калькуляторов (tiered / fixed / weight)
site/
  cakes/                 ← 30 адаптивных страниц тортов (десктоп + мобилка)
  index.html             ← каталог
  about.html             ← о нас
```
